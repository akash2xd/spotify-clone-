# 🎵 Spotify Clone
This repository contains a Spotify Clone built with HTML, CSS, and JavaScript. It’s a front-end project inspired by the popular music streaming platform Spotify, focusing on replicating its UI and adding basic interactivity.

📌 Features
🎧 Modern UI inspired by Spotify’s design

🎵 Play, pause, and skip functionalities

📃 Dynamic song list display

🔊 Responsive design for desktop and mobile

🖱️ Interactive buttons and hover effects

🚀 Tech Stack
HTML5 – for structuring the app

CSS3 – for styling and responsive layouts

JavaScript (ES6) – for adding interactivity and basic media control

🎯 Goals of the Project
Practice front-end skills by cloning a real-world application UI

Improve DOM manipulation and event handling in JavaScript

Learn responsive design and CSS animations
